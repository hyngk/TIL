모든 데이터는 모델에 들어가기 전에 숫자 형태의 텐서가 되고, 데이터의 종류가 모델의 입력 shape를 결정한다
# 데이터의 종류
| 종류 | 예시 | 특징 |
|---|---|---|
| 정형 데이터 | CSV, SQL 표 | 행과 열이 명확 |
| 반정형 데이터 | JSON, XML, 로그 | 태그나 키가 있음 |
| 비정형 데이터 | 이미지, 음성, 자연어 | 고정된 표 구조가 없음 |

정형 뎅터에서는 Random Forest, XGBoost 같은 트리 모델도 여전히 강력하다

비정형 데이터에서는 CNN, RNN, Transformer같은 딥러닝 모델이 주로 사용된다
## 정형 데이터의 변수 종류
- 수치형: 키, 매출, 온도
- 명목형: 색상, 국가, 제품 종류
- 순서형: 낮음/중간/높음, 만족도1-5
- 이진형: 예/아니오, 정상/불량
## 데이터 종류와 모델 연결
표 데이터       → MLP, XGBoost\
이미지          → CNN, ResNet, ViT\
텍스트          → RNN, Transformer, BERT, GPT\
시계열          → LSTM, Transformer\
그래프          → GCN, GAT

모델은 데이터의 구조에 맞춰 선택한다
- 이미지는 주변 픽셀 관계가 중요하므로 CNN
- 시계열은 시간 순서가 중요하므로 RNN/LSTM
- 텍스트는 멀리 떨어진 단어 사이의 관계가 중요하므로 Transformer
## 이미지·텍스트·시계열 표현
### 이미지
이미지는 픽셀 숫자의 배열이다
- 흑백 이미지: (H,W)
- 컬러 이미지: (C,H,W)
- 배치까지 포함: (B,C,H,W)

예를 들어 224x224 RGB 이미지 한 장은:
(3,224,224)\
32장을 묶으면:
(32,3,224,224)

PyTorch는 채널이 앞에 오는 NCHW 형식을 주로 사용한다
### 텍스트
문장은 토큰으로 쪼갠 뒤 정수 ID와 임베딩 벡터로 바꾼다

문장->토큰->정수 ID->임베딩 벡터

대표 shape:
(B,T,D)
- B: 배치 크기
- T: 토큰 개수
- D: 임베딩 차원
### 시계열
시계열은 순서가 있는 데이터다

예:
- 공장 센서
- 주가
- 전력 수요
- ECG/EEG

대표 shape:
(B,T,D)

시간 순서를 섞으면 미래 정보가 과거 학습에 들어갈 수 있으므로 시계열 데이터는 과거에서 미래 방향으로 분할해야 함
# 데이터의 품질
모델을 만들기 전에 EDA를 해야한다

확인할 것:
1. 데이터 크기와 shape
2. 변수 분포
3. 결측치
4. 이상치
5. 클래스 불균형
6. 변수 간 관계
## 결측치
NaN,NULL,None 등으로 표시된다

발생 원인에 따라 세 종류로 나뉨
- MCAR: 완전히 무작위로 발생
- MAR: 다른 관측 변수와 관련되어 발생
- MNAR: 결측값 자체와 관련되어 발생

처리 방법:
- 결측 행 제거
- 결측 열 제거
- 평균 대체
- 중앙값 대체
- 최빈값 대체
- 모델 기반 대체

일반적으로 이상치가 있으면 평균보다 중앙값이 안전하다
## 이상치
정상적인 값에서 지나치게 벗어난 값

원인은 다음 세 가지일 수 있음
- 측정 오류
- 입력 실수
- 실제로 드문 사건

탐지 방법:
- Z-score
- IQR
- 3-sigma rule
- Isolation Forest

중요한 점:
이상치를 무조건 제거하면 안됨\
제조 불량, 금융 사기처럼 이상치 자체가 중요한 정보일 수 있다
## 클래스 불균형
예를 들어 정상 거래가 99.7%, 사기 거래가 0.3%라면 모두 정상이라고 예측해도 정확도가 99.7%

그래서 불균형 데이터에서는 Accuracy만 보면 안됨

사용할 지표:
- Precision
- Recall
- F1-score
- ROC-AUC
- PR-AUC

처리 방법:
- Oversampling
- Undersampling
- SMOTE
- Class weight
- Focal loss
# 데이터 누수
학습 시점에는 알 수 없어야 할 정보가 학습 데이터에 들어가는 현상

예를 들어 전체 데이터에 대해 먼저 StandardScaler를 적용하면 Test데이터의 평균과 분산이 Train에 섞인다

올바른 순서:
1. 먼저 Train/Validation/Test 분할
2. Train 데이터로만 fit
3. Validation/Test에는 transform만 적용

잘못된 순서:
전체 데이터로 scaler fit -> 그 후 train/test 분할

시계열에서는 무작위 분할도 누수의 원인이 될 수 있다
# 전처리
## 결측값 처리
평균 대체: 분포가 대칭적일 때

중앙값 대체: 이상치가 있을 때

최빈값 대체: 범주형 변수일 때
## 스케일링
변수들의 크기를 비슷하게 맞추는 과정

스케일링이 필요한 모델:
- KNN
- K-means
- SVM
- 신경망
- 경사하강법 기반 모델

트기 기반 모델은 스케일링의 영향을 거의 받지 않는다
### StandardScaler
$$
x'=\frac{x-\mu}{\sigma}
$$
결과:
- 평균 0
- 표준편차 1

이상치가 적을 때 적합하다
### MinMaxSacler
값을 보통 [0,1] 범위로 변환한다
### RobustScaler
중앙값과 IQR을 사용하므로 이상치에 강하다

기본 선택       → StandardScaler\
0~1 범위 필요   → MinMaxScaler\
이상치 많음      → RobustScaler
## 범주형 변수 인코딩
### 명목형
순서가 없는 범주

e.g.\
제품=모터,베어링,기어

One-Hot Encoding사용\
모터   → [1,0,0]\
베어링 → [0,1,0]\
기어   → [0,0,1]

### 순서형
순서가 있는 범주

Low<Mid<High

Ordinal Encoding 사용

# Tensor
딥러닝에서 텐서는 다차원 숫자 배열이다

스칼라 → 벡터 → 행렬 → 3차원 텐서 → 4차원 텐서 → ...
| 형태 | 차원 |
|---|---:|
| 숫자 하나 | 0차 |
| 숫자 한 줄 | 1차 |
| 표 | 2차 |
| 이미지 묶음 | 4차 |
| 영상 묶음 | 5차 |

컬러 이미지 한 장은 RGB 채널까지 포함해 3차원이고 여러장을 배치로 묶으면 4차원이 된다
## Rank,Shape,Size
e.g.
$$
T\in \mathbb{R}^{2\times3\times4}
$$
- Rank: 축의 개수 -> 3
- Shape: 각 축의 크기 -> (2,3,4)
- Size or numel: 전체 원소 수 -> 2 x 3 x 4 = 24
## dtype과 device
텐서는 세 가지 속성이 중요하다
- shape
- dtype
- device

대표 dtype:
- float32: 학습에 가장 흔함
- float16: 메모리 절약
- int64: 분류 정답 라벨
- bool: True/False
- uint8: 이미지 원본 픽셀

device는 텐서가 CPU에 있는지 GPU에 있는지를 나타냄

## 모델별 입력 shape
| 모델/데이터 | Shape | 의미 |
|---|---|---|
| MLP/표 데이터 | `(B,F)` | 배치, 특징 |
| CNN/이미지 | `(B,C,H,W)` | 배치, 채널, 높이, 너비 |
| RNN/텍스트·시계열 | `(B,T,D)` | 배치, 시간, 특징 |
| 영상 | `(B,T,C,H,W)` | 배치, 시간, 채널, 높이, 너비 |

예를 들어 이미지가 CNN을 통과한 뒤 Linear 층으로 들어가려면 펼쳐야 한다\
(B,C,H,W) → (B,C×H×W)

## 텐서가 중요한 이유
텐서는 딥러닝에서 세 가지 역할을 함
1. 모든 데이터를 저장한다
2. GPU에서 빠르게 계산한다
3. 자동미분을 통해 기울기를 계산한다

신경망 학습은 결국 손실을 줄이는 방향으로 파라미터를 수정하는 과정임
$$
w \leftarrow w-\eta\frac{\partial L}{\partial w}
$$
