# AI, ML, DL
AI: 인간의 지능을 흉내 내는 모든 기술

ML: 데이터에서 패턴을 학습하는 알고리즘

DL: 여러 층의 신경망으로 특징을 자동 학습하는 머신러닝

**AI > ML > DL**

| ML | DL |
|---|---|
| 사람이 특징을 설계 | 모델이 특징을 자동 학습 |
| 데이터가 비교적 적어도 가능 | 대규모 데이터 필요 |
| 연산량이 상대적으로 적음 | GPU 등 높은 연산량 필요 |
| Feature Engineering | Representation Learning |

예를 들어 스팸 메일을 분류하는 경우\
ML: 사람이 직접 다음 특징을 만듦
- 특정 단어가 있는가?
- 느낌표가 많은가?
- 발신자가 의심스러운가?

DL: 원문 메일을 입력하면 모델이 중요한 특징을 스스로 찾아냄
# 인공신경망의 기본 원리
인공 뉴런은 입력값에 가중치를 곱하고 더한 뒤 활성화 함수를 통과시킨다
$$
y=f(w_1x_1+w_2x_2+\cdots+w_nx_n+b)
$$
- x: 입력
- w: 가중치
- b: 편향
- f: 활성화 함수
- y: 출력
## 구조
입력층 -> 은닉층 -> 은닉층 -> 출력층

은닉층을 여러 개 쌓으면 저수준 특징에서 고수준 특징까지 단계적으로 학습한다

이미지:\
픽셀 -> 엣지 -> 형태 -> 객체

텍스트:\
문자 -> 단어 -> 구 -> 문장

음성:\
파형 -> 음소 -> 음절
# 머신러닝의 학습 방식
## 지도학습
입력과 정답이 함께 있는 데이터로 학습

목표는 예측값과 정답의 차이인 손실을 최소화하는 것

대표 문제:
- 분류: 스팸/정상, 고양이/강아지
- 회귀: 주택 가격, 온도, 수요량 예측
## 비지도학습
정답 없이 데이터 자체의 구조를 찾는다
- 군집화: 비슷한 데이터끼리 그룹화
- 차원 축소: 고차원 데이터를 저차원으로 압축
- 밀도 추정: 데이터 분포 추정

대표 모델:
- K-means
- DBSCAN
- PCA
- Autoencoder
- VAE
## 준지도학습
소량의 정답 데이터와 대량의 정답 없는 데이터를 같이 사용한다

정답을 붙이는 비용이 큰 의료영상, 제조 결함검사 등에 유용하다
### 자기지도학습과 준지도 학습의 차이
- 준지도학습: 사람이 만든 정답을 일부 사용
- 자기지도학습: 사람이 만든 정답 없이 데이터가 문제와 정답을 스스로 생성\
예를 들어 GPT는 앞의 단어들을 보고 다음 토큰을 예측하며 학습한다

공통점: **비레이블 데이터**를 활용해 레이블링 비용을 줄인다

## 강화학습
에이전트가 환경과 상호작용하면서 보상을 최대화하는 행동 정책을 학습한다

상태 -> 행동 -> 보상 -> 새로운 상태

예:
- AlphaGo
- 로봇 제어
- 게임 AI
# 딥러닝의 역사
## 1943: 매컬럭-피츠 뉴런
최초의 수학적 인공 뉴런 모델
- 입력을 가중합
- 임계값을 넘으면 1
- 그렇지 않으면 0

하지만 가중치를 스스로 학습하지는 못했다
## 1956: Dartmouth Workshop
Artificial Intelligence라는 분야가 공식적으로 시작된 시점
## 1958: Perceptron
Rosenblatt가 제안한 최초의 학습 가능한 신경망

학습 규칙: $
w_i \leftarrow w_i+\eta(y-\hat y)x_i
$
- 실제 정답과 예측값의 차이를 이용해 가중치 조정
- 선형 분리 가능한 문제에서는 수렴 보장

하지만 단층 퍼셉트론은 XOR문제를 해결하지 못했다
## 1969-1980: XOR문제와 제 1차 AI겨울
단층 퍼셉트론은 직선 하나로 분리할 수 있는 문제만 해결할 수 있다\
XOR은 직선 하나로 두 클래스를 분리할 수 없기 때문에 퍼셉트론의 한계가 드러났다

결과:
- 신경망 연구에 대한 기대 하락
- 연구비 감소
- 제 1차 AI 겨울
## 1986: 역전파
Rumelhart, Hinton, Williams가 역전파를 널리 알렸다.

핵심
1. 입력에서 출력 방향으로 계산한다
2. 출력 오차를 계산한다
3. 체인룰을 이용해 오차를 뒤쪽에서 앞쪽으로 전달한다
4. 각 가중치를 수정한다

역전파는 모델 자체가 아니라 효울적으로 그래디언트를 계산하는 방법이다
## 1987: 제 2차 AI 겨울
신경망을 깊게 만들면 기울기가 점점 작아지는 기울기 소실 문제가 발생함

시그모이드 함수의 최대 기울기가 0.25정도이므로 여러 층을 지나면서 기울기가 급격히 줄어든다

결과적으로 앞쪽 층이 거의 학습되지 않는다
## 2006: 사전학습과 DBN
Hinton은 층별 사전학습을 이용해 좋은 초기 가중치를 얻었다
- 레이블 없는 데이터도 활용 가능
- 역전파 시 기울기 소실 완화
- 딥러닝이라는 용어가 본격적으로 사용되기 시작
## 2012: AlexNet
딥러닝 혁명의 시작으로 보는 사건

핵심 기술:
- ReLU
- Dropout
- GPU 병렬 연산
- 대규모 ImageNet데이터
### 딥러닝 혁명의 3대 원동력
- 빅데이터
- GPU연산
- 알고리즘 혁신

셋중 하나만으로는 부족하고 세 가지가 동시에 성숙하면서 딥러닝이 폭발적으로 발전했다
## 이후의 주요 발전
2014: GAN\
2015: ResNet\
2017: Transformer\
2018: BERT, GPT\
2022: ChatGPT와 LLM 대중화
# 주요 모델 계열
모델은 데이터의 모양과 목적에 따라 선택한다
| 데이터/목적 | 대표 모델 | 핵심 아이디어 |
|---|---|---|
| 표 형태 데이터 | MLP | 완전연결층 |
| 이미지 | CNN | 주변 픽셀의 지역적 패턴 |
| 시계열·음성 | RNN, LSTM, GRU | 이전 정보를 기억 |
| 언어·토큰 시퀀스 | Transformer | Attention으로 전체 관계 파악 |
| 새 데이터 생성 | VAE, GAN, Diffusion | 데이터 분포 학습 |
## CNN
이미지처럼 격자 구조를 가진 데이터에 적합하다

가까운 픽셀끼리 관련 있다는 가정을 사용한다
## RNN
시계열 데이터에서 이전 시점의 정보를 다음 시점에 전달한다

하지만 긴 시퀀스에서는 기울기 소실 문제가 발생한다
## LSTM
RNN의 기울기 소실 문제를 해결하기 위해 게이트를 사용한다
- 망각 게이트: 과거 정보를 얼마나 버릴지
- 입력 게이트: 새 정보를 얼마나 저장할지
- 출력 게이트: 어떤 정보를 출력할지
## Transformer
RNN처럼 순차적으로 처리하지 않고 Attention으로 모든 위치를 동시에 본다

장점:
- GPU 병렬화 가능
- 긴 거리의 의존성 학습
- BERT, GPT, ChatGPT의 기반

순환이나 합성곱 없이 Attention만으로 시퀀스를 처리한다
## GAN
두 신경망이 경쟁한다
- 생성자 G: 가짜 데이터를 생성
- 판별자 D: 진짜와 가짜를 구분

생성자는 판별자를 속이도록 학습하고 판별자는 더 잘 구분하도록 학습한다

문제점:
- 학습 불안정
- Mode Collapse
# 신경망을 분류하는 4가지 기준
1. 피드포워드 vs 순환
- 피드포워드: 입력에서 출력으로 한 방향만 흐름
- 순환: 이전 시점의 은닉상태를 현재 계산에 사용
2. 얕은 신경망 vs 깊은 신경망
- 얕은 신경망: 은닉층 1-2개
- 깊은 신경망: 은닉층 3개 이상\
깊어질수록 더 추상적인 특징을 학습한다
3. 결정적 모델 vs 확률적 모델
- 결정적 모델: 같은 입력이면 항상 같은 출력
- 확률적 모델: 내부에 샘플링이나 무작위성이 있음\
VAE,GAN,Diffusion은 대표적인 확률적 모델
4. 판별 모델 vs 생성 모델
- 판별 모델: P(y|x)를 학습하고 정답을 예측
- 생성 모델: P(x) 또는 P(x,y)를 학습하고 새 데이터를 생성

CNN은 대표적인 판별 모델이고 VAE,GAN,Diffusion은 생성모델이다
