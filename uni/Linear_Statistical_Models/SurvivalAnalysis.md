# 생존분석
사건의 발생과 **발생까지 걸린 시간**을 설명하고 예측
- 시간(T)이 우리의 관심사
- 설명 + 예측

사건(의학)==실패failure(신뢰성)

하나의 연구에서 여러 개의 사건이 발생하는 경우는 다루지 않음 - 하나의 사건만이 일어난다고 가정

logit or probit 모형: Y가 0아니면 1일 때 취하는 모형 (사건의 발생만을 고려)\
생존분석: 사건의 발생 여부+발생까지 걸린시간을 모형 내에서 동시 분석\
time to evnets
- continuous time
- discrete time

## data
1. 각 개체마다 사건이 시작되는 시간과 끝나는 시간이 다름\
-> 생존시간이 정규분포를 따른다고 가정할 수 없음
2. 연구기간 내 follow up을 실패할 수 있음\
중도절단(censored)관측(중도절단과 사건발생은 서로 관련없음)

censoring데이터를 다루는게 중요한 문제

### Type of censored data
- uncensored: end time 이전에 사건 발생
- right cnesored: end time까지 사전 발생하지 않음 (신뢰성 분석에서 대부분)
- left cnesored: 시작하는 시점이 불분명한 것 
- interval censored
## 주요 용어
T: 특정 사건까지의 발생시간(확률변수)\
T>0인 모든 숫자가 가능

t: T가 가질 수 있는 특정 값

d: 중도절단 or 실패
- 0: 중도절단
- 1: 사건발생(실패)

P(T>5)=S(5)\
F(t): 누적확률 CDF
### 주요 함수
기초 통계량 - 생존분석에서는 중도절단자료로 인해 평균,분산 등 안씀
1. survival function: Time-Survival probability - S(t)
2. hazard function: 위험률
3. cumulative hazard function
4. mean residual life - mrl

생존과 위험률은 반대. 둘 중 하나가 정해지면 다른 하나는 정해짐 e.g. 생존률 80% -> 위험률(사건이 발생할 확률) 20%
# Survival Function
S(t)=P(T>t)\
t=5->5년 초과 생존 확률

S(t)=P(T>t)=1-P(T<=t)<-누적확률

생존함수는 비증가함수

S(0)=1,S(무한대)=0\
t(0<=t<무한대), 0<=S(t)<=1

- 이론적인 생존함수: 곡선
- 실제 생존함수: 매끈한 곡선이 아닌 계단 형태

두 개의 생존함수 비교(그룹별로 -투약x,투약o)

# Hazard Function
생존함수가 1에서 시작해서 감소하는것과 달리 위험함수는 아무 곳에서나 시작해도됨

시간이 흐름에 따라 증가,감소 가능

생존함수는 그 시간까지 누적생존을 나타내지만 위험함수는 순간적인 실패 가능성을 알려줌
# MRL
x시점 이후 평균잔여수명

x시점까지 생존했을때 x 시점 이후 생존 가능한 시간의 기댓값
# 모수적 분포
parametric 추정: 분포 앎 -  지수, 와이블분포\
non-parametric추정: 보통 이거 - KM

지수분포,와이블분포-> 아 이거 생존데이터구나

지수분포는 사간이 지나도 위험률이 변하지 않음 so 산업데이터,보건데이터엔 많이 쓰이지 않음. 와이블분포 많이씀

와이블분포: 지수분포에 parameter추가해서 가변하는 위험함수를 갖도록한 분포
## 비모수적 방법
Kaplan-Meier Curve: 직접적으로 생존함수 S(t)를 추정
1. 가장 간단한 추정량\
사건수/전체
2. 해당 구간에서만 중도절단된 경우를 제외\
사건수/(전체-중도절단)
3. 중도절단된 모든 경우를 제외\
사건수/(전체-전체중도절단)

1 생존율 과대 추정 경향, 2 3 과소추정 경향\
대부분 2번 채택
